# 🔐 Gerador de Senhas Aleatórias

Um projeto desenvolvido em **Python** com o objetivo de gerar senhas aleatórias utilizando letras maiúsculas, minúsculas, números e caracteres especiais.

## 🚀 Funcionalidades

- Geração de senhas aleatórias.
- Escolha de caracteres usando `random.choice()`.
- Definição do tamanho da senha.
- Armazenamento das senhas em uma lista.

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca `random`

## 📚 Conceitos praticados

- Variáveis
- Listas
- Funções (`def`)
- Laços de repetição (`for`)
- Bibliotecas (`import`)
- Escolha aleatória (`random.choice()`)
- Adição de elementos (`append()`)

## ▶️ Como executar

1. Tenha o Python 3 instalado.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```

## 🎯 Objetivo

Este projeto foi criado para praticar lógica de programação e aprender conceitos fundamentais da linguagem Python.
